# Sign Language Recognition using Deep Learning

A deep learning project for recognizing American Sign Language (ASL) alphabet gestures using TensorFlow and Keras.

## Features

- CNN built from scratch using TensorFlow/Keras
- Data augmentation for improved generalization
- MobileNetV2 transfer learning experiment
- Model evaluation using confusion matrix and classification report
- Saved trained model for inference

## Tech Stack

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
